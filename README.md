# GFG-Store

Starter Python package scaffold for the GFG-Store project.

## Overview

This repository contains a minimal Python package layout to get started with GFG-Store. It includes a minimal implementation, tests, CI workflow, and packaging configuration.

## Install (editable)
```
python -m venv .venv
source .venv/bin/activate  # Linux / macOS
.venv\Scripts\activate     # Windows
pip install -e .
```
## Run
```
python -m gfg_store
```
## Tests
```
pytest
```
